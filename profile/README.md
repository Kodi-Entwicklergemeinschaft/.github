# Kodi-Entwicklergemeinschaft

Open-source reference applications for **KODI – Kommunen Digital**: digital services for
German municipalities ("Kommunen") — mobile apps, web frontends, and backend services.

These are template-based reference implementations (Template A / B / C) covering listings,
events, citizen services, community forums, and more. Most repositories are licensed under
the **EUPL-1.2**.

## Getting started

Each repository has its own `README` with setup and configuration instructions. Browse the
repositories below to find the component you need.
